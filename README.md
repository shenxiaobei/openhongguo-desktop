# 红果原生桌面版

**OpenHongguo Desktop · 1.0 · Windows 10 / 11 x64**

一个使用 WPF 原生窗口、内嵌视频播放器的 Windows 短剧客户端。支持搜索找剧、题材筛选、排行榜、连续推荐、选集播放和观看记录。

本项目基于并借鉴 [beilunyang/openhongguo](https://github.com/beilunyang/openhongguo) 二次开发，保留原作者版权与许可证；Windows 原生桌面功能在其 SDK 基础上扩展。

从 [GitHub v1.0 发行页](https://github.com/shenxiaobei/openhongguo-desktop/releases/tag/v1.0) 下载 Windows 完整包，解压后双击 `红果原生桌面版.exe`。.NET 桌面运行时、SDK 桥和视频组件已内置，使用时无需另装 Edge、mpv、ffplay 或 ffmpeg。本地成品位于源码同级的 `Releases/v1.0/`。

## 1.0 更新 · 2026-11-09

本次在现有 **v1.0** 发行入口更新源码与 Windows 附件，包含以下桌面功能和播放修复。产品版本继续为 **1.0**；同版本的不同构建以发行日期及 SHA256 清单区分。

- 原生 Windows 单 EXE，内嵌视频播放，不依赖浏览器或本地网页服务。
- 默认完整显示并保持原比例；可选择「拉伸铺满」，保留全部画面和字幕，按窗口比例铺满。
- 透明紧凑控制栏、真实搜索联想、下一集预解码、官方系列跨季连播，以及按顺序保存观看进度。
- 真实滚动弹幕随播放时间显示，自动读取后续时间段；可开关、调整区域、字号、不透明度、滚动速度和密度。
- 修复普通码流描述、校验字段被误判为加密而触发「播放信息暂不可用」；所有剧集共用规则，失败模型不缓存。
- 普通与动态播放组按实际分辨率、同档码率择优；窗口缩小时保留更多细线与轮廓，并抑制边缘振铃。
- 空白标题栏，隐藏左侧小图标，保留拖动区域与最小化、最大化、关闭按钮；窗口内全屏与 F11 屏幕全屏独立。
- 收起跨应用浮层，并约束原生窗口层级，减少切换到其他应用时的覆盖。

**验证范围：**原生弹幕渲染 37 项、设置 8 项、自动加载 10 项、生产播放集成 8 项通过，并重新通过原讨论区 10 项回归。真实 libmpv 输出已核对文字移动、暂停、跳转、倍速、关闭、画质重载、预加载交接与缩窗；离屏设置菜单也已检查。测试使用本地样片和受控后端，不等同于所有远端剧目、其他电脑或完整桌面合成验收。详细结果与本地历史见[验证与范围](docs/native-desktop.md#验证与范围)。

播放修复另通过 90 个加密字段组合用例、真实明文及加密片源和自动续播验证。画质修订核对真实 HEVC 同帧软硬解码、原尺寸与缩小输出，并通过画质/预加载 8 项回归；缩小呈现的改善有限，不代表恢复片源已损失的细节，也未证明与 iPhone 使用同一份视频。

## 功能

| 功能 | 当前实现 |
|---|---|
| 搜索与发现 | 输入约 300 ms 后显示最多 8 条服务端联想，支持方向键或鼠标选词；「剧集 / 综合 / 视频」分类和分页，新搜索回到列表顶部 |
| 按题材找剧 | 组合选择平台提供的体裁、主题、人物设定、故事背景等条件 |
| 排行榜 | 剧目逐行展示名次、封面与热度；顶部横向切换榜单，支持题材筛选、加载更多和每日刷新 |
| 连续推荐 | 连续加载候选内容，在视频区域用滚轮或 ↑ / ↓ 切换另一部剧 |
| 播放控制 | 拖动进度、暂停、音量、0.5–3 倍速；默认最高画质，提供当前分集实际档位，并显示当前播放档位、分辨率和片源码率 |
| 自动连播 | 提前缓冲同一季的下一集；确认官方合集关系及下一季可播放时，支持同系列跨季连播 |
| 观看记录 | 带封面的并列卡片，保存集数与播放位置，继续上次观看 |
| 窗口适配 | 默认保持原比例和完整画面；「拉伸铺满」保留全部画面并跟随窗口比例，缩放、全屏和切集沿用选择；小窗口收拢侧栏与次要控制，应用不设置最小宽高 |
| 沉浸播放 | 窗口内全屏和屏幕全屏；透明控制栏，静止约 3 秒后隐藏控制栏与鼠标 |
| 封面与统计 | 解码平台真实海报；展示接口提供的播放、追剧、本集点赞和评论数量 |
| 评论与弹幕 | 官网公开评论预览；真实时间轴列表可点击定位；片内滚动弹幕自动续读，支持开关、范围、字号、不透明度、速度及密度设置 |

画质选项随具体分集变化。SDK 完整解析普通 `video_list` 和 `dynamic_video` 两组，比较各组的 `best`，采用实际尺寸短边分辨率最高、同档码率最高的一组；平手保留普通组，已有可用普通组时，损坏的动态组不影响播放。视频、音轨和保护信息始终取自同一组，手动选档也在所选组内按分辨率、码率择优。这里的最高仅指当前接口返回的可用候选，不证明 iPhone 与桌面使用相同码流。

齿轮「画质」页优先展示实际解码分辨率；尚未就绪时显示接口片源尺寸，码率取接口提供的值。拉伸窗口只改变显示大小，不会增加片源细节。

窗口小于片源时，播放器使用保留细节的缩小滤镜并抑制边缘振铃，改善默认缩放对细线、远景轮廓的柔化。媒体直接交给内嵌播放器解码，本地没有重新编码压缩；片源本身的压缩损失仍会影响清晰度，此调整也不增加原视频的分辨率或码率。

讨论区的评论是官网公开预览，显示预览条数与来源总数，未提供完整评论分页。滚动弹幕只使用服务端真实正文及毫秒时间轴，通过内嵌播放器渲染，暂停、拖动进度和播放倍速均随视频同步。齿轮「弹幕」页可开关、选顶部 1/4 / 半屏 / 全屏、调整小中大字号、20%–100% 不透明度以及速度、密度；全屏范围仍为底部字幕预留空间。默认开启、半屏、中号字、85% 不透明度，偏好在本地保存。右侧时间轴列表继续提供点击定位。收藏量尚未接入；接口缺失的统计值显示为 `—`，追剧数与收藏数分别处理。接口与渲染说明见[评论和弹幕](docs/discussion-api.md)。

弹幕使用中性灰 `#D5D9DC`、细描边和轻阴影，按媒体时间渐入 220 ms、淡出 300 ms。中号字在视频实际显示高度达到 540 像素时略微缩小，小窗保留原字号；用户保存的不透明度及其他显示设置继续生效。

播放模型现在按明确的加密标记区分普通流与加密流，普通码流描述和完整性校验数据不再触发密钥解包，修复这一类片源出现「播放信息暂不可用」的问题。该规则由所有剧集共用，普通组与动态组一致；最高分辨率、同档最高码率的选择规则保持不变。失败模型不进入两分钟缓存，点击「重试」会重新请求播放信息。实际验证范围见[原生桌面版说明](docs/native-desktop.md)。

1. 解压完整包并双击 `红果原生桌面版.exe`；本地交付也可直接打开 `Releases/v1.0/` 运行。
2. 在「发现」「排行榜」或搜索结果中点击剧目，进入播放页。输入关键词时会显示服务端联想：↑ / ↓ 选词，Enter 搜索选中词，未选词则直接搜索当前输入；Esc 收起，也可用鼠标点击候选。失焦、切换应用或调整窗口时会收起候选。
3. 通过选集、进度条和齿轮「播放设置」调整观看；倍速、画质、画面模式、弹幕和自动连播均在设置中。
4. 退出时保存观看进度，下次从「观看记录」继续。

升级前先正常关闭旧程序，再替换 EXE；观看记录和弹幕偏好保存在用户配置目录，替换程序文件不会主动清空它们。请保留完整包中的第三方许可证和组件来源说明。远端附件采用英文文件名，完整 ZIP 内的程序名称为 `红果原生桌面版.exe`。

首次启动会校验并释放内置运行组件，耗时可能比后续启动更长。成品以单 EXE 交付，运行时仍会创建组件、封面、配置和历史文件。

## 播放操作

| 操作 | 效果 |
|---|---|
| 空格 | 暂停 / 继续 |
| ← / → | 快退 / 快进 5 秒 |
| 播放器全屏按钮 | 窗口内全屏，播放区域扩展到当前客户区，保留窗口大小、位置及系统标题栏，沿用画面模式 |
| 标题栏最大化按钮 | 按系统工作区最大化 / 还原窗口，保留标题栏，沿用画面模式 |
| F11 或双击视频 | 进入 / 退出屏幕全屏，进入时隐藏系统标题栏，沿用画面模式 |
| Esc | 先退出屏幕全屏，再退出窗口内全屏 |
| 视频区域滚轮或 ↑ / ↓ | 在「连续推荐」模式中切换另一部剧 |

两种沉浸模式下，鼠标接近顶部或底部、操作快捷键会重新显示控制栏；中央移动只恢复鼠标。拖动进度、悬停控制区或打开菜单时保持可见。「全屏」控制播放区域布局，画面模式单独在齿轮菜单选择。默认「完整显示」按原比例保留全部画面，必要时留黑边；「拉伸铺满」保留全部画面和烧录字幕，横纵方向分别缩放至窗口大小，人物比例可能随窗口变化。两种模式均不裁切边缘。选择同步到当前与预加载播放器，调整窗口、切换全屏、最大化及后续切集均沿用；重新打开程序默认完整显示。窗口可继续缩小，但原生标题栏仍受 Windows 系统边界约束。

## 连播、推荐与排行榜

- **下一集预加载**：开启自动连播时，备用播放器提前静音缓冲并准备首帧，就绪后交接；播放地址失效或准备不足时走正常加载流程。切换其他剧目、关闭连播或退出时取消旧准备。
- **跨季连播**：依据平台返回的官方合集 ID、季序和分集信息确认下一季。当前季完结且末集播放结束后接续；相似剧名不作为续季依据。跨季目前预取关联信息，媒体在切季时加载。
- **推荐来源**：使用平台发现、热门目录和相关推荐接口，内容随匿名设备及服务端响应变化。推荐暂不可用时可显示同频道的热门目录，并注明来源。
- **每日榜单刷新**：应用运行期间每分钟检查本地日期，跨天刷新当前榜单；返回过期榜单也会更新。失败时保留旧列表，约 10 分钟后重试；支持手动刷新。此功能刷新榜单内容，软件版本更新需要另行下载。

## 本地数据与缓存

| 位置 | 内容 |
|---|---|
| `%APPDATA%\openhongguo` | 匿名设备配置、观看记录、目录缓存及 `danmaku-settings.json` 弹幕显示偏好 |
| `%LOCALAPPDATA%\OpenHongguo\covers` | 封面图片缓存 |
| `%LOCALAPPDATA%\OpenHongguo\native` | 从 EXE 释放的 SDK 桥和视频运行组件 |
| `%TEMP%\.net\红果原生桌面版` | .NET 单文件程序解包内容 |

视频预加载使用内存，明确关闭磁盘视频缓存。每个播放器的前向媒体缓存上限为 24 MiB，另有 4 MiB 回退缓存；约 12 秒为预读目标，解码帧、音频和 GPU 还会占用额外内存。停止或销毁播放器时释放对应媒体。

评论正文、弹幕时间轴及生成的 ASS 字幕保留在内存中，不另建评论数据库或磁盘弹幕文件；弹幕显示偏好单独保存。

封面缓存的 24 小时有效期用于判断是否复用，目前没有统一的过期删除或容量限制；旧运行组件也可能保留。需要重置时先退出应用，再清理上述目录；删除 `%APPDATA%\openhongguo` 会同时清空观看记录和匿名设备配置。

## 技术实现

- **界面**：C# / .NET 9 / WPF，原生 Windows 窗口。
- **播放**：进程内加载 libmpv，将视频输出到原生窗口句柄；内置其所需的视频组件。
- **弹幕**：独立生成 ASS 时间轴，经 mpv `memory://` 字幕轨内嵌渲染；交互参考 DPlayer，未引入浏览器播放器。
- **接口**：基于 OpenHongguo Go SDK，通过私有标准输入输出 JSONL 管道连接内置桥接进程。
- **海报**：Magick.NET 解码，包括平台返回的 HEIC / HEIF / AVIF 图片。
- **分发**：Windows x64、自包含、单文件 EXE；应用运行时不创建本地 HTTP 服务，也不启动浏览器。

当前网络请求沿用匿名设备机制。目录、榜单、画质和可播放状态取决于平台响应，服务端要求验证、限流或调整接口时可能出现相应提示。项目为非官方客户端，与红果官方无隶属关系。

## 从源码构建

构建环境：**Windows x64、Go 1.22+、.NET 9 SDK、PowerShell 7（pwsh）**，以及恢复 NuGet 依赖所需的网络连接。运行成品无需安装这些开发工具。

源码保留运行库的许可证和头文件，DLL 通过单独的[原生运行库 ZIP](https://github.com/shenxiaobei/openhongguo-desktop/releases/download/v1.0/openhongguo-native-runtime-v1.0-windows-x64.zip) 分发（仅开发构建使用）。先将 `openhongguo-native-runtime-v1.0-windows-x64.zip` 放入源码同级的 `Releases/`，然后在仓库根目录执行：

```powershell
Expand-Archive -LiteralPath '..\Releases\openhongguo-native-runtime-v1.0-windows-x64.zip' -DestinationPath '.' -Force
pwsh -File scripts/build-native.ps1 -OutputDirectory '..\Releases\v1.0' -NoZip
```

脚本校验原生 DLL 的 SHA256，构建 Go 桥，再发布包含 .NET 运行时及原生组件的桌面程序。上述命令直接更新唯一的本地成品目录：

```text
Releases/v1.0/
├─ 红果原生桌面版.exe
├─ 使用说明.md
├─ 第三方组件来源.md
├─ LICENSE
└─ 第三方许可证/
```

运行库来源、校验值和许可证见[原生桌面版说明](docs/native-desktop.md#源码与构建)及[第三方组件来源](docs/native-components.md)。旧浏览器入口源码与脚本保留供回溯，当前 Windows 桌面版使用 `scripts/build-native.ps1` 构建。
