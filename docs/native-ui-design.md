0.3.2 根据用户实际截图重做发现、播放、历史及新增排行榜界面。下方保留各阶段记录，最新变化见 0.3.7。

## 设计取舍

- 以深色背景和有限的珊瑚色强调内容；选中、悬停、键盘焦点和禁用状态分别可辨。
- 播放进入独立影院页，减少导航及搜索占用；返回保留原来的搜索、榜单或历史上下文。
- 主要播放为圆形矢量按钮，前后集、全屏采用图标，进度和音量采用细轨圆点，自动下一集使用开关。
- 倍速、画质菜单使用完整自定义弹出层；选集使用紧凑方格，白色系统滚动条替换为细暗色轨道。控件保留键盘操作和可访问名称。
- 依据实际可用宽度排列两组控制，小窗口分两行，大窗口左右对齐。
- 全屏控制条放在独立原生 Popup 内，覆盖视频而不参与视频布局；静止 3 秒后隐藏，鼠标或键盘操作重新显示。拖动进度、悬停控制区或打开菜单期间保持可见。显隐过程不改变视频区域尺寸。
- 新排行榜使用 SDK 的 ShortRank 真实数据，支持服务端实际目录、榜单和游标；默认热播榜。按接口 Position 显示顺序，热度原样显示，Promoted 行明确标为平台推荐。演员榜属于人物数据，本页仅提供能直接点播的作品榜。
- 自动连播在当前集播放时提前准备下一集播放信息，接近片尾核对签名有效期；复用相同分集和画质的在途或已完成请求，减少片尾等待。准备失败不打断当前视频，关闭连播、跳到其他分集或退出时取消旧准备，不提前下载整集或创建第二个播放器。

## 0.3.3 反馈改进

- 排行榜改为横向海报卡片，自适应换行；1380 宽窗口实测一排 5 张，950 宽一排 3 张，无横向溢出。数字改为实际 Rank，推广位显示「荐」，Position 仅保持响应顺序。
- 推荐榜明确说明当前匿名设备的个性化语义，热门内容可以切到热播榜；顺序及分数继续使用同次平台响应。
- 发现页新增真实题材维度，体裁、主题、设定、背景、排序、受众、时间均读取平台面板。筛选与推荐、搜索分别缓存，分页保留条件。切体裁先移除旧面板，避免选中不属于新体裁的隐藏条件。
- 排行榜内也直接提供主题分类、人物设定、故事背景三个入口，作品类型和平台榜单增加清楚标签。选择题材后按平台热度排序，数字仅为列表序号；没有返回逐项热度分时不编造，清除条件回到原平台榜。题材与发现页选择分别保存，真人、漫剧、AI 使用相应实际体裁，系列剧保留平台榜。
- 排行榜顶部改成两排横向并列标签，上排作品类型、下排平台榜单；各自行内横向滚动，分类入口展开题材面板。按本地日期自动更新当前榜单，最近成功日期按榜单或题材条件分别记录；跨天刷新、当天定时检查去重、失败保留旧内容并延迟重试，返回页面也检查有效日期。
- 播放右栏展示真实互动计数。没有确认的值显示「—」，追剧与收藏分开。当前接口没有评论正文、弹幕及收藏量，面板明确说明，不编造列表或零计数。
- 全屏移除整块不透明底板，背景渐变透明度为 0、56/255、140/255，控件和文字不降低透明度。约 3 秒闲置时，WPF 与两个原生视频子窗口的鼠标和控制栏一起隐藏；操作、失焦和退出全屏恢复局部鼠标。
- 下一集升级为第二播放器静音暂停缓冲并预解码，准备就绪后交换原生视频表面，历史保存不阻塞交接。线上样本 native EOF 事件至已准备帧约 71.29 ms，进度开始推进约 105.52 ms，5 ms 轮询；这属于播放器状态指标，未拍摄视频像素首帧，也非所有网络下的耗时保证。

实际验证：`native/verification/discovery-smoke/results/discovery-smoke.json`、`native/verification/desktop-buffer-smoke/results/desktop-buffer.json`、`native/verification/media-buffer-smoke/results/media-buffer.json`。布局与透明控件截图由真实 WPF 元素渲染，不含原生视频 HWND 画面。

## 0.3.4 推荐错误与逐行榜单

- 排行榜内容按最新反馈改为每部剧一整行，纵向排列；名次、真实封面、完整标题、集数与热度分区展示，整行可点播。顶部作品类型与榜单仍是两排横向标签，题材分类、分页和每日更新继续保留。
- 推荐空结果与设备拒绝分别显示，保留接口错误类型。发现及连续推荐明确返回空内容错误时读取同频道真实热门目录，界面显示来源；续页绑定原方法、来源及频道，避免换频道后复用旧游标。
- 修复推荐打开候选时取消自身请求、过早解除加载状态、初次失败却切成推荐页面的问题。内容明确不可用才跳过候选，设备拒绝、验证、限流及网络错误保留原提示。
- 新逐行榜单证据：`native/verification/ranking-rows-smoke/results/ranking-rows-smoke.json`，真实平台榜和题材热榜、宽窄窗口、封面、顶部分类以及点行返回均通过。旧横向海报几何断言仅代表 0.3.3 历史，不作为当前布局要求。
- 原「自动下一集」改为「自动连播」，覆盖当前季下一集和同系列下一季。官方系列关系、同一非空合集 ID、明确季序与首集可播共同确认后才续季；预告未上线、缺季或关系不明确时停止，连续推荐也先接当前系列。季列表提前读取，跨季媒体在切换时加载，不将其描述为已经预缓冲。
- 最小窗口从 950×640 降为 640×420 逻辑尺寸，同时修改构造函数与 XAML。窄窗使用图标导航及紧凑搜索；播放器右侧栏收起为选集 Popup，复用原分集与讨论入口。低高度题材可折叠并限制滚动区域；放大与全屏退出恢复对应布局。物理像素随 Windows 缩放变化，不以 100% 尺寸冒充高 DPI 下的实际窗口。

## 0.3.5 取消应用最小窗口尺寸

- 根据最新反馈移除 Window 的最小宽高设置。小于原可用内容尺寸时外层视口提供横向、纵向滚动，保持内部控件可读；内容画布最小尺寸不约束用户拖动窗口。Windows 原生标题栏的系统边界继续适用。
- 放大与全屏恢复原布局，极小窗口选集浮层尺寸保持合法。媒体预加载明确固定为内存策略，持久封面和运行组件的实际清理边界写入使用说明。

## 0.3.6 小窗直接适配与首次关闭修复

- 用户截图确认上一阶段的固定内容画布导致矮窗只看到部分视频，进度和按钮落到窗口外。取消 RootLayout 的固定与最小内容尺寸，外层不再滚动；播放区域直接按可见客户区分配剩余空间。
- 窄、矮窗口保留一行主要播放按钮和进度；上一集、时间文字等按可用宽度收起，下一集切为图标，倍速、画质、音量及自动连播复用原控件移到「更多」弹层。放大后恢复内联设置。选集与设置弹层互斥，尺寸随窗口变化，内部可滚动。
- 全屏保留透明控制栏与鼠标闲置隐藏；设置弹层展开时保持可见，F11/Esc 可在弹层内使用，切换、导航和关闭恢复控件父级及鼠标状态。
- 真实复现首次关闭异常：历史保存同步完成时，同轮 Closing 内再次 Close 触发 WPF VerifyNotClosing。现先退回 Dispatcher 消息循环，再完成保存和资源释放；清理中再次关闭继续等待，资源释放后才允许销毁。
- 定向证据：`native/verification/adaptive-player-smoke/results/adaptive-player-smoke.json` 与 `native/verification/closing-smoke/results/closing-smoke.json`；旧版本关闭堆栈保留在 `closing-baseline.json`。WPF PNG 仅证明控件布局，真实画面适配另由 HWND 客户区、libmpv OSD 尺寸、黑边及原始比例核实。

## 0.3.7 播放器窗口内全屏

- 右下角按钮改为窗口内全屏：隐藏播放标题、侧栏和普通控制行，视频占满当前客户区，外窗位置、尺寸、标题栏、最大化状态及可调整边框保留。再次点击或 Esc 退出。
- 窗口内模式与屏幕全屏状态分别记录，只共享沉浸布局条件。右上角为系统最大化；F11 和双击视频仍进入屏幕全屏，从窗口内模式进入后退出恢复先前模式，Esc 可逐级返回。按钮提示随当前动作分别显示窗口内全屏或退出屏幕全屏。
- 两种沉浸播放复用透明控制层与闲置鼠标隐藏，窗口移动和缩放主动刷新独立 Popup 的定位，放大/还原不应将控制栏留在旧屏幕位置。导航、菜单、关闭恢复控件父级，保持 v0.3.6 的一次关闭处理。
- 专项实际证据见 `native/verification/window-cinema-smoke/results/window-cinema-smoke.json`；只在定向验证范围内描述外窗、原生视频与浮层位置，非激活测试不当作前台鼠标计时体验验证。
