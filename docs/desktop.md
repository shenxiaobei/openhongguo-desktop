# 红果桌面版使用说明

这是基于 openhongguo 的 Windows 桌面入口。双击 `红果桌面版.exe` 即可打开搜索、剧集详情和选集界面，使用成品不需要安装 Go。

## 开始使用

1. 将发布 ZIP 解压到一个普通文件夹，不要直接在压缩包里运行。
2. 双击 `红果桌面版.exe`。
3. 界面打开后，可以浏览推荐内容，或输入剧名搜索。
4. 打开一部剧，选择分集并点击播放。视频会在本机播放器中打开。

推荐 Windows 10/11 的 64 位系统。程序优先使用系统已有的 Microsoft Edge 打开独立窗口；未检测到 Edge 时，使用默认浏览器打开本机界面。

## 播放器

搜索和浏览不需要额外播放器。播放需要本机已有 mpv、ffplay 或 VLC；程序会检查播放器是否可用，并在界面显示检测结果。请将播放器所在文件夹加入 PATH 后重新启动桌面版。

- mpv、ffplay 可以直接播放项目支持的媒体。
- 使用 VLC 处理部分媒体时，还需要 ffmpeg。
- 桌面版不会自动下载或安装播放器。

## 退出

点击界面的“退出应用”结束程序。直接关闭界面后，本机服务会在约 90 秒没有界面心跳后自动退出；正在进行的播放任务会随程序退出而取消。

## 出现错误时

启动失败会弹出错误窗口。运行中的网络、接口和播放器错误会留在界面中，可查看错误后重试。设置或诊断页面会显示配置目录和日志位置。

桌面版继续使用原项目的匿名接口。服务端返回限制、超时、空播放信息时，界面会显示对应错误；重新打开窗口不代表服务端一定会恢复。请以实际请求结果为准。

配置默认保存在 Windows 用户配置目录下的 `openhongguo` 文件夹。程序的浏览器界面使用该目录下的独立 `desktop-browser` 配置，不使用日常 Edge 的登录状态。

## 从源码构建

在仓库根目录运行 PowerShell：

```powershell
.\scripts\build-desktop.ps1
```

构建产物为 `dist\windows-amd64\红果桌面版.exe`，同时生成包含说明和许可证的 ZIP。源代码构建需要 Go 1.22 或更高版本；直接使用成品 EXE 不需要 Go。

诊断时可在终端运行：

```powershell
.\红果桌面版.exe --no-browser --listen 127.0.0.1:18766 --idle-timeout 10m
```

此模式仅供本机诊断，不自动打开界面。程序输出的启动链接包含当前会话信息，请勿分享完整链接或配置中的设备数据。
