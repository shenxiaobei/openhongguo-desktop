# 红果原生桌面版 1.0

本说明对应当前 **1.0** 桌面版。下载页为[本仓库 Releases](https://github.com/shenxiaobei/openhongguo-desktop/releases/tag/v1.0)，完整包为 `OpenHongguo-Desktop-v1.0-windows-x64.zip`，单 EXE 为 `OpenHongguo-Desktop-v1.0-windows-x64.exe`。软件基于并借鉴 [beilunyang/openhongguo](https://github.com/beilunyang/openhongguo) 二次开发，保留原作者版权与许可证。

当前版隐藏标题文字和标题栏左侧的小图标，保留原生标题栏的拖动区域及最小化、最大化、关闭按钮。窗口内全屏仍保留标题栏，F11 屏幕全屏隐藏整条标题栏；不修改 EXE 文件图标，保留窗口大图标供任务栏使用。

当前标题栏净化、浮层层级、缩窗画面模式、历史顺序与搜索联想修订日期：2026-11-06（Asia/Taipei）。图标重设计按用户要求暂停，本轮只隐藏标题栏中的图标，不重新设计图标资源。

Windows 10/11 x64 原生窗口，视频直接嵌入程序。双击 `红果原生桌面版.exe` 使用；程序包含 .NET 桌面运行时、SDK 和视频解码组件，不需要另装 Edge、mpv、ffplay、ffmpeg 或 .NET。

## 使用

1. 双击 EXE，在「发现」页浏览或搜索剧名。输入停顿约 300 ms 后显示最多 8 条联想；↑ / ↓ 选择，Enter 搜索选中词，未选词时搜索当前输入，也可直接点击候选。Esc 收起列表。
2. 点击卡片自动播放，右侧可直接选集。
3. 主栏提供进度、播放/暂停、上一集/下一集、时间和全屏按钮；普通模式位于画面下方，沉浸模式为顶部短浮条。点击齿轮打开紧凑「播放设置」菜单：倍速、画质和画面模式各占一行，右侧显示当前值，点击后在同一面板内选择；自动连播开关和音量也各占一行。宽窗还可在主栏调整音量。画质只列出当前分集实际提供的档位，切换保留进度和暂停状态；默认开启「自动连播」，支持下一集及同系列下一季。
4. 「连续推荐」支持视频区域滚轮或 ↑ / ↓ 切换另一部剧，队列继续获取后续推荐；一部剧内仍按自动下一集设置连播。
5. 空格暂停，← / → 快退或快进 5 秒。主栏全屏按钮切换「窗口内全屏」：保留窗口大小、位置和系统标题栏，隐藏播放标题及侧栏，视频宿主使用全部客户区。右上角最大化按钮按系统工作区扩大窗口并保留标题栏；F11 或双击画面进入屏幕全屏并隐藏系统标题栏。进入这三种状态时均恢复「完整显示」，按比例保留完整画面。设置菜单打开时，Esc 先收起菜单；随后 Esc 先退出屏幕全屏，再退出窗口内全屏。
6. 关闭窗口保存观看进度并结束本窗口创建的 SDK 进程。
7. 「排行榜」每部剧占一整行，纵向依次展示名次、封面、完整剧名、集数和平台实际提供的热度。顶部两排横向标签分别切换作品类型、平台榜单，选项较多时可横向滚动；右侧「分类」展开主题、人物设定、故事背景，可组合选择。题材模式按平台热度排序，数字为当前列表序号；点击「全部题材」回到原平台榜单，平台榜的数字取实际名次，「荐」为推荐位。两种模式均支持加载更多、点击整行观看及返回保留列表。推荐榜会按当前匿名设备返回内容，热播榜更适合找热门作品。
8. 「按题材找剧」读取平台真实的体裁、主题、设定、背景、排序、受众和时间条件，可组合筛选并翻页。例如悬疑属于主题、重生属于设定；电影和搜索保留各自的接口。
9. 播放页右侧展示平台实际返回的播放、追剧、本集点赞和评论数量，未返回的值显示「—」。当前 SDK 没有提供评论正文、弹幕内容或收藏量，讨论面板会说明数据状态；追剧数与收藏数分开处理。

新版采用统一的深色影院界面，播放时收起导航与搜索。普通模式使用 44 DIP 高的单行主栏，进度与按钮排在同一行；倍速、画质、画面模式与连播始终收进齿轮设置，窄窗的音量也从设置调整。时间、上一集及主栏音量按可用宽度收拢，播放、下一集、设置和全屏入口保留。设置菜单宽约 240 DIP，高度随内容自然测量；根菜单为五行，倍速、画质和画面模式进入带当前勾选标记的选项页，保留返回入口。设置内不再显示大下拉框或「换个故事」按钮，后者仍可从播放标题处进入。选集继续通过独立浮层打开，菜单均为深色样式。

窗口内全屏和屏幕全屏取消固定底部控制带，视频宿主使用全部客户区，不因主控隐藏而留出额外空白。顶部控件层底板和边框 alpha 均为 0，只为控件内容保留轻微黑色阴影以提高辨识度，不再绘制整块底板。布局高 44 DIP、宽度最多 860 DIP，通常距顶部 12 DIP，主控远离底部字幕区域。普通模式位于画面下方的底栏保持原样，齿轮设置弹层继续使用可读的深色底；约 3 秒隐藏规则不变。透明底板不代表按钮和进度线本身不可见，也不保证视频中任意位置的烧录文字都无遮挡。控件显隐不改变视频布局，进入或退出沉浸模式、调整窗口大小时再适配可用区域。「全屏」只控制播放区域布局；调整窗口宽高，或进入窗口内全屏、屏幕全屏、系统最大化时，自动恢复「完整显示」，保持原始比例和全部画面，片源比例与窗口不同时仍会出现正常黑边。

只有主动打开「齿轮 → 画面模式 → 裁切铺满」时，画面才按比例放大并裁切边缘，不会拉伸人物；视频与窗口比例差距较大时，可能切掉字幕或其他内容，可随时切回「完整显示」。裁切设置仅适用于当前窗口尺寸；尺寸不变时，当前播放器与预加载播放器保持同步，下一集交接沿用当前模式。调整窗口宽高，或进入窗口内全屏、屏幕全屏、系统最大化时，会同时将两个播放器恢复为完整显示，避免缩窗后沿用裁切而丢失字幕；如仍需裁切，可在新尺寸下重新选择。重新打开程序也默认完整显示。

沉浸播放中，鼠标接近顶部 76 DIP 或底部 64 DIP 热区时展开顶部操作栏，中央移动只恢复鼠标；操作播放快捷键也会显示控制栏。静止约 3 秒后控制栏与鼠标一起隐藏，拖动进度、悬停控制区、展开菜单或使用键盘在控制栏内操作时保持可见。设置面板从顶部浮条向下展开，普通模式从底栏向上展开，并按客户区限制尺寸；F11 继续切换屏幕全屏。DIP 是 Windows 逻辑尺寸，实际像素高度随系统显示缩放变化。

控制浮条、设置和选集均为归属播放器主窗口的普通浮层，不使用跨应用系统置顶。展开及计时路径除 WPF 激活状态外，还核对真实系统前台是否属于本播放器；跨进程失活时从原生通知收回浮层。切换到其他应用、最小化或隐藏播放器时收起控制浮层、设置菜单及下拉框，并恢复鼠标；后台鼠标活动或延迟事件不会据此重新打开浮层。回到播放器前台后恢复正常交互，退出沉浸播放时恢复普通窗口的控制区。本次原生层级修订的验证结果以随包记录为准。

应用不设置窗口最小宽高，可以继续拖小；原生标题栏仍遵循 Windows 的系统边界。播放页直接跟随实际可用视口缩放，不保留固定大画布或整窗滚动条；调整宽高会恢复完整画面并按比例缩放，进度和主要按钮留在窗口内，极矮窗口收起次要标题信息。窄窗导航自动收成图标，悬停显示名称；播放器收起固定右侧栏，通过顶部「选集」打开浮层。重新放大或进入全屏会恢复相应布局。

开启自动连播时，应用会在当前集播放期间提前取得下一集的播放信息，由第二个内嵌播放器静音、暂停地缓冲媒体并准备首帧。前向缓存限制约 12 秒及 24 MiB；缓存达到至少 2 秒、或已读完、或达到字节阈值，且首帧和画面参数均就绪时，切集直接交换已经准备好的播放器。已准备好的切集不再等待原播放器重新联网和解码；URL 过期、准备不足或失败时正常加载。手动切集、切换画质的媒体加载也不再先等待旧播放记录写入完成。记录在切换时立即捕获快照，再按全局队列顺序写入，媒体请求继续并行，避免连续切集时旧记录晚到而覆盖新进度；单条保存失败不阻断后续记录。导航清空当前剧集后，关闭窗口仍等待已排入的记录完成。关闭自动连播、切换其他剧集或退出会取消旧准备；额外播放器会增加一定内存和解码开销。

视频缓冲放在内存中，程序明确关闭 `cache-on-disk`。每个播放器的前向数据上限为 24 MiB，另有 4 MiB 回退缓存；约 12 秒是预读目标，不是整个应用内存用量，解码帧、音频和 GPU 另占空间。切集交接会停止旧播放器，换剧、取消预加载和关闭连播会停止相应准备，退出销毁两个解码器。媒体数据随停止/销毁释放，不会每集写出一个视频缓存文件；进程工作集不一定立即回落。

封面图片另存于 `%LOCALAPPDATA%\OpenHongguo\covers`，目前 24 小时仅控制是否复用，不代表自动删除过期文件，也没有总量清理策略。`%LOCALAPPDATA%\OpenHongguo\native` 和 .NET 单文件解包位置存放运行组件，旧版本也可能保留。首页目录缓存与观看记录在 `%APPDATA%\openhongguo`；首页缓存覆盖同一文件，观看记录长期保存。这些持久文件与内存中的视频预加载不同，本次不新增磁盘清理功能。

播放器默认保留完整画面，竖屏短剧和横屏内容均适应窗口，空余区域保留黑边；「裁切铺满」为当前窗口尺寸下主动选择的按比例裁切模式，调整尺寸、进入全屏或系统最大化时恢复完整显示。卡片使用接口实际返回的系列海报，内置 HEIC 解码，不再用分集截图替代。目录先显示、海报后台补齐；再次打开优先显示最近缓存并更新。连续推荐使用发现分页、热门目录和相关推荐接口；内容由服务端返回。发现或推荐明确返回空内容错误时，应用尝试同频道的真实可用目录，并显示来源，例如「热门目录（推荐暂不可用）」。正常分页结束不会重新开启其他来源，电影也不会混入短剧。

连续推荐的队列和分页按频道分别管理，打开自己的推荐候选时保持请求有效，加载期间不接受重复切换。只有平台明确返回内容不可用的候选才会跳过，一次最多尝试五部、读取一页；设备拒绝、账号验证、限流和网络错误保留原提示并停止，避免反复重试。

多季作品会在播放期间读取平台官方系列剧关联，并核对各季的非空合集 ID、季序号和实际分集。开启「自动连播」后，当前季确认完结且最后一集播放结束，才接续准确的下一季，从第一集开始；连续推荐模式也优先接同系列。相似剧名不作为续季依据，缺季、下一季预告未上线、第一集受限或关联冲突时停止并显示原因。关闭自动连播就保持当前集；导航或换剧会取消旧的季列表查询。已有的媒体预加载用于同一季的下一集，跨季目前预取关联信息，切季时仍需加载下一季媒体。

搜索默认「剧集」，可显式切换「综合」「视频」。联想复用 SDK 的真实 `Suggest` 接口，不用搜索第一页猜测补齐；输入停顿约 300 ms 才请求，最多显示 8 条，在内存中缓存最近的前缀结果，旧词响应不会覆盖新输入。中文输入法组合期间不提交联想；失焦、切换应用、移动或缩放窗口、进入播放及关闭时收起候选。联想为空、失败或稍慢时仍可按 Enter 直接搜索原词。服务端建议可能是剧名、主题或其他相关搜索词，不保证词条都对应完整剧集，也不代表所有资源均已收录。新关键词、分类、刷新都回到顶部，加载更多保留当前位置；结果与分页参数来自原 SDK。观看记录以带封面的卡片并列展示。内置桥的状态版本统一为 `1.0-native.1`，桌面产品版本仍为 `1.0`。

排行榜按本地日期每天自动更新。程序开着时每分钟检查一次，跨天后刷新当前展示的榜单或题材组合；从视频返回过期榜单也自动更新，同一组合当天已更新后不重复执行定时刷新。关闭程序后，下次打开仍会读取最新榜单。网络失败保留上次数据，约 10 分钟后自动重试，也可以手动刷新；页面显示最近成功更新时间。此功能更新榜单内容。

## 验证与范围

### 当前标题栏修订

2026-11-06 标题栏专项 **11/11**，检查空标题、小图标抑制、保留系统按钮与可调边框、缩窗和最大化还原、窗口内全屏及 F11 往返、关闭和资源释放。测试还注入非零图标，确认清除小图标时保留大图标原值。这是透明离屏夹具的原生状态验证，不等同于桌面外观、任务栏像素或在线播放验收。

最新成品单 EXE 隔离启动通过：缩减 PATH、外部 DOTNET_ROOT 不存在，标题长度 0、小图标 0、原生按钮及可调边框保留，约 4904 ms 响应；约 165 ms 自然关闭、exit 0，无强杀、监听或残留，仅创建内嵌 SDK 桥。CUA 可视核对启动了响应中的新窗口，但 AX 无内容，刷新和重置后截图仍 FrameArrived 超时，实际标题栏外观与任务栏像素仍待核对。当前标题栏改动不消除下面透明控制层的未决交互验收。

## 单 EXE 的工作方式

对外只需复制一个 EXE。程序首次运行自动将内置 SDK 桥、libmpv 和 Vulkan 组件校验并释放至 `%LOCALAPPDATA%\OpenHongguo\native\版本标识`；.NET 与图片解码原生库由单文件运行时自动解包。随后在进程内加载视频库、以私有标准输入输出管道连接 SDK 子进程。此设计不创建本地 HTTP 服务，不启动浏览器，不要求用户安装外部工具。

匿名设备和观看记录沿用 `%APPDATA%\openhongguo\anonymous.json`、`history.json`。诊断日志只记录错误类型和接口方法，不记录播放密钥或完整媒体地址。此版本与旧浏览器入口分开，建议从新名称的 EXE 启动。

网络和内容接口仍使用 openhongguo 原有匿名 SDK。服务端要求账号、验证或未返回内容时，界面显示对应错误并提供重试入口。单 EXE 打包解决本机依赖；远端接口的响应仍取决于服务端。

## 源码与构建

- 界面及播放器：`native/Hongguo.Desktop/`。
- SDK 管道桥：`cmd/ohg-native-bridge/`、`internal/nativebridge/`。
- 编译：Go 1.22+、.NET 9 SDK；运行成品无需这些开发工具。
- 执行：`powershell -File scripts/build-native.ps1`。
- 产物：`dist/native-windows-amd64/红果原生桌面版.exe`。
- 历史浏览器入口构建脚本 `scripts/build-desktop.ps1` 保留供旧版回溯；当前桌面交付使用 `build-native.ps1`。
