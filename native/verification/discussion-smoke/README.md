通过真实 `MainWindow`、生产 `BackendClient` 和受控 stdio 后端检查讨论区。窗口始终不调用 `Show`，不创建播放器、不请求网络、不读取用户配置，也不操作前台。

```powershell
dotnet run --project DiscussionSmoke.csproj -c Release
```

输出 `results/discussion-smoke.json` 与 `results/discussion-panel-offscreen.png`。PNG只渲染340×680 DIP的讨论栏，检查正文换行和末行布局；不包含原生视频、窗口合成或桌面。时长用例直接调用生产读取方法验证保护与重试；新集播放就绪后自动触发的调用点另由代码审查核对，不在此加载媒体。
