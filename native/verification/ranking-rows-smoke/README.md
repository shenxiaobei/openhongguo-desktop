# 纵向榜单行的真实 WPF 验证

本项目只创建自己的透明、屏幕外 `MainWindow`，复用生产资源和独立匿名状态，通过当前窗口对象与真实 Go bridge 验证，不使用系统 UIAutomation、系统输入或窗口激活。

```powershell
dotnet run --project RankingRowsSmoke.csproj -c Release
```

运行目录为本文件夹，输出 `results/ranking-rows-smoke.json`，并生成 `ranking-rows-wide.png`、`ranking-rows-compact.png`、`ranking-rows-topic.png`。报告只保存真实作品、布局数值、封面像素摘要及筛选条件，不保存凭据、媒体地址和完整不透明游标。

检查 1380×900 与 950×640 下的全宽单列、首两项同 X 且 Y 递增、水平边界、标题换行且不强制省略、首两张真实封面解码；保留两排平台目录标签、题材展开/收起及每日更新时间。悬疑热门列表与同一次真实响应核对顺序，并检查 SDK 游标中的 `category_dim_theme=cate_165`、`sort=hot_score`，续页验证零重复与序号连续。

点播导航使用真实行按钮和后端发送锁，逐项核对真实详情响应中的剧目 ID。为了不启动媒体播放，测试在请求发送前使本窗口的详情版本过期，随后使用真实返回按钮检查列表、题材、游标与滚动位置保留。此项只验证点播导航和返回，不将它描述为完整播放验收。
