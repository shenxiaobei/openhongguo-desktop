# 空白标题与标题栏小图标定向验证

使用生产 `MainWindow`，只移除 `Window_Loaded` 后显示透明离屏窗口。不改生产 `Title`，不启动 SDK 后端或媒体解码，不读写用户配置、缓存和观看记录。

覆盖：WPF 与 Win32 标题为空、标题栏小图标句柄为空、窗口模式保留 `WS_EX_DLGMODALFRAME` 且屏幕全屏移除、大图标原值保留、原生标题栏/系统菜单/最小化/最大化/可调边框保留、辅助功能名称保留、进程主窗口发现、642 × 373 缩放、最大化/还原、窗口内全屏、屏幕全屏往返、一次显式关闭以及消息钩子/计时器资源清理。

图标专项先给本测试窗口临时补回非零大小图标，再连续调用两次生产 helper，确认小图标清理有效且幂等，不改变窗口位置、尺寸和非零大图标；最后恢复原大图标值。这样即使宿主初始大图标为零，也能验证 helper 的保留行为。`ICON_SMALL2` 的查询值也记录于 JSON，但系统可按 DPI 与默认图标回退返回句柄，因此不作为标题栏绘制结论。任务栏可见图标及标题栏实际合成由最终成品的可视检查另行核对。

在仓库根目录运行：

```powershell
dotnet run --project .\native\verification\caption-title-smoke\CaptionTitleSmoke.csproj -- "..\Releases\verification-v1.0\caption-clean"
```

JSON 包含逐项断言、生产源文件 SHA-256 与范围说明。原始标准输出由执行命令另行保存。旧 `title-hidden` 结果保留，不覆盖。本测试不模拟实际网络内容播放，不代表可见桌面合成或字幕适配验收。
