# 片内弹幕生产播放集成验证

使用真实生产 `MainWindow`、生产 JSONL 客户端、本地受控 stdio 后端与真实双 libmpv 解码器。测试直接走 `PlayEpisodeAsync`、画质重载、预解码交接、快捷开关、D 键与正常停止路径，不手动调用 `SetDanmaku` 或 ASS 渲染器。

构建后在本目录运行，参数为现有 60 秒静态横竖屏样片：

```powershell
dotnet build RollingPlaybackSmoke.csproj -c Release --nologo
& './bin/Release/net9.0-windows/win-x64/RollingPlaybackSmoke.exe' '<竖屏样片绝对路径>' '<横屏样片绝对路径>'
```

八项顺序回归覆盖：关闭讨论面板时生产播放仍请求并显示原生弹幕、暂停与 seek 使用媒体时间轴、关闭面板保留独立轨、主栏关闭后像素清空及 D 键恢复、拉伸和缩窗时按真实输出宽高比重新生成 ASS 且始终只留一条弹幕轨、同集切画质重新挂轨并复用已读正文、真实备用播放器提升后只显示新集正文且继续默认最高画质、停止时清空轨道与缓存正文。用例有顺序依赖，应从首个失败分析。

测试配置与偏好使用隔离临时目录；窗口放在屏幕外、不激活、不进任务栏且透明，不占用用户前台；正常关闭后清理隔离目录。视频静音且不请求线上内容。

`results/rolling-playback-smoke.json` 记录结果。截图通过 **libmpv 自身** `screenshot-to-file` 生成：`video` 为不含外挂字幕的同帧基线，`subtitles` 为包含原生 ASS 的视频输出，二者逐像素比较证明文字确实在原生渲染链内；另保留一次 `window` 视频输出。截图没有桌面、WPF 控件、系统浮层或前台合成，不作为桌面鼠标操作验收。暂停使用完全相同像素断言，seek 比较新增文字像素重心，关闭后要求与无字幕基线一致。此测试不覆盖线上弹幕来源、网络时延、真实用户鼠标操作或全部渲染参数，独立 renderer 验证负责字体、范围、密度等细项。
