# 真实跨季自然 EOF 验证

本程序创建屏幕外、透明、不激活的真实 WPF `MainWindow`，使用生产播放器和内嵌后端。
每次运行新建独立 `state/时间戳`，只复制匿名设备状态，不读取或覆盖用户观看记录。

在仓库根目录执行：

```powershell
dotnet run --project native/verification/seasons-online-smoke/SeasonsOnlineSmoke.csproj -c Release
```

结果写入运行目录的 `results/seasons-online-smoke.json`；退出码 0 表示四项均通过。
推荐先进入本目录运行，以集中保存独立状态及结果。

验证范围：

1. 真实官方跨季关联：全球死考 S1 `7675400266065136665`，S2 `7680524320346475582`，合集 `7679071746556693528`；S1 实际最后可播分集为第 152 集。
2. 关闭自动连播，最后一集通过真实媒体自然 EOF 后停在 S1，并持久化已看完记录。
3. 开启自动连播，重播末集并自然 EOF 后进入 S2 第一个实际可播分集，确认解码首帧、播放进度及两季独立记录。
4. 停止后清理媒体、季信息与预加载请求；通过仅代理验证宿主自有后端输入流，确认没有 `feed` 或 `recommend` 请求，推荐队列及游标保持一致。

EOF 通过跳至媒体结束前 0.65 秒并继续播放触发，不直接调用生产结束处理函数。
报告中的跨季耗时是当前网络与设备条件下的单次观察值，不作为无缝播放保证。
SDK 错误会保留为失败结果，不进行循环重试；请求报告仅保留方法与对象 ID。
