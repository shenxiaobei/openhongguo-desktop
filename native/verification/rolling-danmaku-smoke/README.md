# 滚动弹幕加载生命周期验证

通过生产 `MainWindow`、真实 `BackendClient` 和可控 stdio 假后端，验证视频内弹幕的数据加载。窗口始终不调用 `Show`，不创建播放器，不访问网络或用户配置，也不操作前台窗口。

从本目录运行：

```powershell
dotnet run --project RollingDanmakuSmoke.csproj -c Release
```

检查未打开讨论栏时读取、播放时间推进自动续段、远距离跳转获取目标附近、关闭开关取消并停止请求、重新开启复用本集缓存、旧集迟到响应隔离、连续错误退避及成功恢复、十二段内存上限与内容去重、精确毫秒时长和片尾条目，以及远距离跳转替换仍在等待的旧位置请求。慢后端故意在收到取消后继续返回迟到响应，生产 JSONL 客户端与窗口必须保持状态隔离。

退避用例先检查生产代码设定的 5/15/60 秒截止时间，再将私有截止时间推进到过去触发下一次受控尝试，避免空等真实时间；并在每次截止前反复触发生产时间更新，确认没有提前重试。缓存上限用例跨多个播放位置实际请求新时间段，检查当前条目有序且按时间与正文去重。

输出 `results/rolling-danmaku-smoke.json`。本项目验证加载状态机与请求边界，不验证 ASS 像素运动、播放器暂停/倍速同步、字幕轨或桌面视频合成；这些由原生渲染专项验证。测试首次构建会通过项目引用编译生产工程，应与其他共享该工程 `obj` 的构建串行执行。
