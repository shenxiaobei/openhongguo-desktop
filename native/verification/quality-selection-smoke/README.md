# 原生画质切换定向验证

通过本地 stdio 假后端、生产 JSONL 客户端与真实双 libmpv 解码器，检查画质请求、实际解码分辨率、来源元数据、暂停与进度、无效档位拒绝及下一集预解码交接。

从本目录运行：

```powershell
dotnet run --project QualitySelectionSmoke.csproj -c Release
```

默认使用 `../mpv-smoke/sample.mp4`（360×640）及 `sample-landscape.mp4`（1280×720）；也可在 `--` 后按顺序传入两个样片绝对路径。样片应至少 20 秒，建议使用现有四边标记、两行字幕样片。依赖恢复方式与主桌面工程相同。

八项顺序回归覆盖默认最高画质、ComboBox 切低画质、具体 720p 档位、未提供档位不发请求、预加载不覆盖当前集说明、真实备用解码器提升后更新尺寸和来源信息、离屏画质菜单的信息布局，以及真实异步播放错误清除旧片源说明。媒体切换项比较真实 `MpvStatus.VideoWidth/VideoHeight`，不会仅用菜单文字证明媒体切换。假后端中码率是受控元数据，本项不测真实压缩视频码率、线上选流或与手机观感的差异。

第七项临时将来源元数据改为错误尺寸，确认当前说明仍优先采用真实解码尺寸，再恢复原值。随后直接调用生产 `SetPlaybackMenuPage("quality")`，在始终关闭的 Popup 子树内，以 240 DIP 宽测量、排列、渲染 WPF 菜单，输出 `results/quality-menu-offscreen.png`。检查说明文本、换行与末字符布局，以及信息块处于实际滚动视口内；不打开系统浮层，也不进行鼠标、前台或桌面视频合成验收。

第八项在已有真实解码与片源信息的基础上，使用当前生产播放器加载隔离目录中确定不存在的本地媒体，由真实 libmpv 事件循环触发 `CreatePlayer` 注册的 `Error` 处理器。检查异步错误已到达生产窗口、当前元数据被清空、画质说明变为尚未就绪且没有旧尺寸码率，再执行正常生产停止路径。该项不直接调用或伪造错误事件。

输出 `results/quality-selection-smoke.json`。测试隔离配置和历史目录，退出时走生产窗口关闭路径；没有线上服务请求，不读取用户匿名配置。使用离屏测试窗口及直接方法/ComboBox 状态，不验证鼠标菜单、系统前台或桌面合成。八项用例存在顺序依赖，前置失败后的后续错误需要结合首个失败分析。
