# 选剧与互动的真实 WPF 验证

本项目创建独立、透明的生产 `MainWindow`，在自己的 WPF Dispatcher 中操作应用对象，不使用系统输入、系统 UIAutomation 或浏览器。独立匿名配置复制到 `state/<时间>/`，不改用户观看记录；报告不记录凭据、媒体地址或完整不透明游标。

```powershell
dotnet run --project DiscoverySmoke.csproj -c Release -p:GenerateSupportedTargetFrameworkAlias=false
```

需要先构建生产内嵌的 Go bridge，并准备 .NET 9、Magick.NET 和 libmpv 运行库。

检查横向排行榜在宽窗与 950×640 下横向并排和边界、平台推荐榜解释、真实题材分组、悬疑筛选及第二页、搜索切出再恢复题材条件，以及真实互动数和缺失正文/弹幕/收藏量。目录与榜单对照同一次后端响应，避免不同时刻的推荐结果产生假差异。输出为 `results/discovery-smoke.json` 和对应 PNG；WPF 截图不包含原生视频 HWND 像素。
